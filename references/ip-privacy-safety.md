# IP, Privacy, and Emotional Safety

## Rights modes

### Licensed mode

Use official names, logos, stills, or character art only when the user confirms they hold an appropriate license or supplies rights-cleared assets. Record the source path in the working notes. Do not remove attribution or rights notices.

### Personal fan-expression mode

Allow a personal, non-commercial parody-style result when the host policy permits it. Prefer user-supplied imagery or newly generated composition rather than copied marketplace screenshots. Add this footer:

> 粉丝向人格娱乐内容，与版权方无隶属或授权关系。角色权利归原权利人所有。

Do not describe this footer as legal clearance.

### Original archetype mode

Use this by default for a public GitHub repository, paid product, brand account, advertising, merchandise, or uncertain authorization.

- Keep the private analysis mapping to the canonical character.
- Render an original underwater workplace archetype with a distinct name and design.
- Do not reproduce protected logos, episode stills, signature costumes, exact silhouettes, or copied catchphrases.
- Replace “Bikini Bottom” in public commercial artwork with a generic label such as “Benthic Workforce Archive” unless permission exists.

### Placeholder mode

Use the bundled neutral placeholder when no safe image source or image tool is available. A strong typographic card is better than unverified art.

## Repository rule

Never bundle:

- marketplace or Xiaohongshu screenshots;
- frames from episodes or films;
- scraped character PNGs;
- third-party fan art;
- official logos or franchise fonts;
- image files whose license cannot be documented.

The bundled example uses a neutral placeholder and must not imply endorsement.
Replace it only with an original or rights-cleared avatar supplied for the specific profile.

## Conversation privacy

- Use only content the current agent can actually access.
- Ask before searching a user-approved export folder or external memory source.
- Do not scan unrelated directories, other users' files, browser history, credentials, or private databases.
- Paraphrase evidence; do not publish verbatim private messages by default.
- Remove phone numbers, email addresses, client names, employer names, project codenames, access tokens, health information, and financial details.
- Store the minimum profile data needed for the card.
- Do not upload conversation exports or avatars to external services without user awareness and host authorization.

## Emotional safety

- Frame the result as entertainment and self-expression, not diagnosis.
- Validate difficult workplace feelings without presenting unverified accusations as fact.
- Make the “workplace wound” situational, not a permanent flaw.
- Pair every wound with agency through the boundary line.
- Do not equate burnout, anxiety, neurodivergence, or disability with a cartoon character.
- Avoid ranking users as smarter, more valuable, or more employable based on conversation style.
