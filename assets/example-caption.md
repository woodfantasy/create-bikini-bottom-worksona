# Agent 说我是「深海全自动补锅机」

让 Agent 翻完我这段时间的聊天，它给我的打工人格是：深海全自动补锅机。

最扎心的不是像 勤快小海绵 · 海绵宝宝型，而是这句：
“不是我爱加班，是每个坑都刚好长成了我的工位。”

聊天记录就是在这三处把我卖了：
① 把模糊想法拆成能落地的清单
② 追到交付闭环才肯真正收工
③ 一边吐槽一边把事情救回来

隐藏技能：把“顺手改一下”还原成十二项真实需求
常见工伤：越靠谱，越容易成为默认兜底人

本人现在决定把这句贴在工位上：
“我可以负责，但不接受无限续杯。”

你觉得自己更像谁？要不要也让 Agent 翻一下聊天记录。
